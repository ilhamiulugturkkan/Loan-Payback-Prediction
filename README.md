# Loan Payback Prediction

A simple machine learning project where I go through the full data cycle for a loan payback prediction problem.

I worked on:

- data preprocessing
- exploratory data analysis
- feature engineering
- training ML models
- comparing Decision Tree and Random Forest results

I tried to explain my thought process throughout the project, including why I made certain choices and what I noticed while working with the data.

The goal of this project was mainly to practice building a complete ML workflow from start to finish, not just training a model and calling it a day.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook
